# COMOSEN
COMOSEN adalah sebuah aplikasi penghitung digital berbasis web yang sangat interaktif dan dilengkapi dengan fitur-fitur canggih. Aplikasi ini dirancang tidak hanya untuk sekadar menghitung melalui ketukan manual, tetapi juga memanfaatkan teknologi kecerdasan buatan (AI) ringan dan sensor kamera untuk otomatisasi penghitungan.
